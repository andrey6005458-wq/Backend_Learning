🚛 ERP для бартерных перевозок

Автоматизация учёта рейсов, топлива, бетона и расчёта взаимозачётов с контрагентами. От Telegram-бота для водителей до автоматических отчётов в конце месяца.

📅 Пример: август 2026 🚛 51 рейс · 3 самосвала ⚡ ~150 часов экономии в год

📥 Часть 2: Автоматический импорт Excel от РБУ

1
РБУ направляет Excel на корпоративный email Например, на barter@company.ru — файлы «Топливо_август.xlsx» и «Бетон_август.xlsx»
2
Система проверяет почту каждые 5 минут Через IMAP: обнаруживает письмо, скачивает вложение
3
pandas парсит Excel Читает листы «Топливо» и «Бетон», извлекает данные
4
Валидация каждой строки Проверяются дата, машина, объём, цена
5
Защита от дублей Повторный импорт того же файла не создаёт дубликаты
6
Сохранение в PostgreSQL SQLAlchemy записывает данные в таблицу barter_operations
7
Пересчёт остатков и взаимозачётов Остатки ТМЦ и баланс с РБУ обновляются автоматически
8
Уведомление менеджеру в Telegram «Импортировано 38 записей топлива. Сальдо с РБУ: −708 659 ₽»
⏱️ Время импорта: 30 секунд вместо 30 минут ручного ввода. Экономия — 2–3 часа ежемесячно.

🛠️ Стек технологий

Backend и API

Backend
FastAPI
Асинхронный веб-фреймворк. Обрабатывает запросы от бота, панели и парсера.
Валидация
Pydantic
Проверяет данные на входе. Не допускает сохранения некорректных значений.
ORM
SQLAlchemy 2.0
Работа с PostgreSQL через Python-классы. Вместо SQL — модели и объекты.
Миграции
Alembic
Версионирование схемы БД. Изменение модели → миграция → применение.

Хранилища

Основная БД
PostgreSQL 16
Справочники, рейсы, бартер, остатки. Транзакции, индексы, аналитика.
Кеш / Очереди
Redis
Кеш запросов и брокер для Celery. Хранение в памяти, микросекунды.
Файлы
S3 / MinIO
Хранение фотографий накладных и Excel-файлов. Локально — MinIO.

Telegram-бот и парсинг

Bot Framework
aiogram 3.x
Асинхронный фреймворк. Кнопки, состояния (FSM), приём фото, диалоги.
Парсинг Excel
pandas + openpyxl
Чтение файлов от РБУ. Извлечение строк, очистка, загрузка в БД.
Email-парсинг
imaplib + schedule
Проверка почты каждые 5 минут. Скачивание вложений, импорт.

OCR и обработка

OCR
Tesseract
Распознавание текста с фотографий накладных. Бесплатный, локальный.
Обработка
OpenCV / Pillow
Препроцессинг: выравнивание, контраст, удаление шума.
Фон. задачи
Celery
Асинхронные задачи: OCR, отчёты, email-рассылки. Не блокирует API.

UI и отчёты

MVP UI
Streamlit
Дашборд и панель управления на Python. Без HTML/CSS/JS.
Экспорт
openpyxl / ReportLab
Формирование Excel и PDF отчётов в конце месяца.

Инфраструктура

Контейнеры
Docker + Compose
Один файл поднимает FastAPI + PostgreSQL + Redis + Celery + MinIO.
CI/CD
GitHub Actions
Автотесты и автодеплой при пуше. Зелёный бейджик — показатель качества.
Прокси
Nginx
HTTPS, статика, проксирование к FastAPI. Домен и SSL-сертификат.
Сервер
Uvicorn + Gunicorn
Продакшн-конфигурация: несколько воркеров, балансировка нагрузки.
